
# Traffic Sign Recognition Using YOLO

This project implements a traffic sign recognition system using YOLO ultralytics and a  dataset containing 8 traffic sign classes containing both self-collected and publicly availaible images. Images were manually collected and then annotated for training and testing purposes.

## Features
- Manually collectd dataset
- Semi-automatic labelling
- YOLO model training
- Multi-class traffic sign detection
